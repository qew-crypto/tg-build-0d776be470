# R Challenge — Fabric 1.21.4

Общее серверное испытание в стиле видео: сначала крутится **событие**, затем русская **буква**, затем **таймер**.

## События

- **Найти предмет** — новый предмет должен появиться в инвентаре одного из игроков.
- **Сломать блок** — один из игроков должен сломать подходящий блок.
- **Убить моба** — один из игроков должен убить подходящего моба.

Название проверяется по официальному русскому переводу Minecraft и должно начинаться с выпавшей буквы.

## Время

- предмет или блок: случайно **60–90 секунд**;
- моб: случайно **5–15 минут**.

Если любой игрок выполняет условие, задание засчитывается всей команде. Через 3 секунды автоматически начинается новая прокрутка. Если время закончилось, все игроки умирают, а испытание ждёт команды `.r reroll`.

## Команды

Команды доступны игрокам с уровнем оператора 2:

- `.r start` — включить испытание;
- `.r reroll` — заменить текущее задание;
- `/r start` и `/r reroll` — запасные варианты с обычным слешем.

## Установка

Мод необходимо установить **и на сервер, и всем игрокам**, поскольку клиент рисует HUD и использует официальный файл `ru_ru.json` для проверки русских названий.

1. Установить Fabric Loader для Minecraft 1.21.4.
2. Установить Fabric API.
3. Положить собранный `rchallenge-1.0.0.jar` в папку `mods` сервера и каждого клиента.
4. Выдать управляющему игроку права оператора (`/op Ник`).
5. Войти на сервер и написать `.r start`.

Требуется Java 21.

## Сборка исходников

```bash
gradle build
```

Готовый файл появится в `build/libs/rchallenge-1.0.0.jar`.

Версии зависимостей находятся в `gradle.properties`.
